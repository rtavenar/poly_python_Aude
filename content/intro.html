Bienvenue !#

Ce document est une version du polycopié Introduction à Python de la filière MIASHS de l’Université de Rennes 2, réécrite pour pouvoir apprendre seul·e, sans cours en présentiel, avec un objectif précis : acquérir les bases nécessaires pour analyser des données (data science) avec Python.

Il vous mène des toutes premières lignes de code jusqu’à l’analyse d’un vrai jeu de données avec les bibliothèques pandas, matplotlib, seaborn et statsmodels. Vous y trouverez :

  • des schémas pour visualiser ce qui se passe dans la machine ;

  • des questions « Testez-vous » au fil de la lecture, pour vérifier immédiatement que vous avez compris ;

  • des exercices progressifs (de ★ à ★★★) avec des indices et des corrections détaillées ;

  • des encadrés « Erreurs fréquentes » qui montrent les vrais messages d’erreur de Python et comment les corriger ;

  • un bilan à la fin de chaque chapitre pour faire le point sur ce que vous savez faire ;

  • des mini-projets pour mettre tout cela en pratique et une fiche mémo pour réviser.

Ce document est distribué librement sous licence CC BY-NC-SA. Le polycopié d’origine a notamment bénéficié des apports d’Aurélie Lemaitre, d’Agnès Maunoury et de Jean-Christophe Burnel. N’hésitez pas à faire vos remarques à son auteur dont vous trouverez le contact sur sa page web.

À qui s’adresse ce document ?#

À toute personne qui souhaite apprendre à programmer en Python pour analyser des données, sans aucun prérequis en programmation. Quelques notions de statistique (moyenne, médiane, quartiles, corrélation, régression) seront utiles dans la dernière partie.

Vous connaissez déjà R ou SAS ?

Ce document a été pensé pour vous aussi ! Vous connaissez déjà la logique de l’analyse de données ; il vous reste à apprendre la syntaxe et les habitudes de Python, qui diffèrent sur des points importants.

  • Des encadrés « Si vous venez de R ou de SAS » signalent, dans chaque chapitre, les pièges à éviter (indices qui commencent à 0, indentation, return obligatoire, copie des listes…) et donnent des tables de correspondance entre R, SAS et Python.

  • Vous pouvez parcourir plus vite les chapitres 1 à 8 : lisez les encadrés « À retenir » et « Si vous venez de R ou de SAS », répondez aux questions « Testez-vous », et faites au moins les exercices ★★. Ne les sautez pas complètement : pandas repose entièrement sur ces bases, et la plupart des erreurs viennent de réflexes R ou SAS appliqués à Python.

  • Le chapitre 14 vous montre comment retrouver vos modèles habituels (lm, glm, PROC REG, PROC LOGISTIC, tests…) avec statsmodels et scipy.

Il suffit de savoir utiliser un ordinateur et d’avoir un peu de patience : apprendre à programmer, c’est un peu comme apprendre une langue étrangère, on progresse surtout en pratiquant régulièrement.

Comment lire les encadrés#

Tout au long de ce document, vous rencontrerez différents types d’encadrés. Voici à quoi ils ressemblent et ce qu’ils signifient.

Objectifs du chapitre

Au début de chaque chapitre : ce que vous saurez faire à la fin.

À retenir

Les points essentiels, à connaître par cœur.

Erreur fréquente

Les pièges dans lesquels (presque) tout le monde tombe au début, et comment s’en sortir.

Testez-vous

Une petite question pour vérifier votre compréhension. Essayez vraiment d’y répondre (dans votre tête ou sur papier) avant de déplier la réponse.

Réponse

La réponse apparaît quand on clique sur le titre de l’encadré.

Exercice 0.1 ★

Un exercice à faire sur ordinateur. Le nombre d’étoiles indique la difficulté :

  • ★ : application directe du cours ;

  • ★★ : demande de combiner plusieurs notions ou de réfléchir un peu ;

  • ★★★ : plus difficile, pour aller plus loin (ne vous découragez pas si vous bloquez !).

Indice

Un coup de pouce si vous êtes bloqué·e. N’ouvrez l’indice qu’après avoir cherché un moment.

Solution

Une correction commentée. Il y a souvent plusieurs bonnes solutions : si la vôtre est différente mais donne le bon résultat, elle est sans doute correcte aussi !

Pour aller plus loin

Des compléments facultatifs, que vous pouvez sauter lors d’une première lecture.

Les indices, réponses et solutions sont repliés : cliquez sur le titre de l’encadré pour les afficher.

Où écrire et exécuter du code Python ?#

Les blocs de code de ce document#

Durant la lecture, vous trouverez des blocs de code tels que celui-ci :

def f(v):
    return v ** 2

x = 5
y = f(3 * x + 2)
print(y)

289

Le bloc situé sous le code correspond à ce qu’affiche ce code lorsqu’on l’exécute.

À retenir

Ne vous contentez pas de lire les exemples : retapez-les vous-même, exécutez-les, puis modifiez-les pour voir ce qui change. C’est de loin la meilleure façon d’apprendre. Évitez le copier-coller, qui donne l’illusion d’avoir compris : taper le code vous oblige à faire attention à chaque détail (parenthèses, deux-points, décalages…).

Option 1 : les fenêtres de code intégrées (version web)#

Dans la version web de ce document, vous trouverez des fenêtres d’éditeur de code vous permettant de tester vos solutions aux exercices directement dans votre navigateur, sans rien installer. En voici une : appuyez sur « Run » pour exécuter le code, puis modifiez le code et observez le résultat en le ré-exécutant.

Option 2 : sans installation, dans le navigateur#

Si vous ne pouvez pas installer de logiciel, le site Basthon propose une console et des carnets (notebooks) Python qui fonctionnent directement dans le navigateur.

Option 3 (recommandée) : installer Python sur votre ordinateur#

Pour travailler confortablement, il est préférable d’installer Python sur votre ordinateur. Deux outils sont utiles, selon la partie du document :

  • Pour les chapitres 1 à 9, le logiciel Thonny est idéal pour débuter : il est gratuit, disponible sous Windows, macOS et Linux, et il installe Python en même temps que lui. Son interface est très simple : une zone éditeur (en haut) pour écrire un programme et l’enregistrer dans un fichier .py, un bouton Run (triangle vert) pour l’exécuter, et une console (en bas) où s’affichent les résultats. Thonny peut aussi afficher les valeurs de vos variables (menu View > Variables), ce qui est très pratique pour comprendre ce que fait un programme.

  • Pour l’analyse de données (chapitres 10 à 14 et projets), on travaille dans des notebooks Jupyter : des documents qui mêlent cellules de code, résultats (tableaux, graphiques) et texte, ce qui est idéal pour explorer des données et garder une trace de son analyse. Le plus simple est d’installer la distribution Anaconda, qui contient Python, Jupyter, numpy, pandas, matplotlib, seaborn, statsmodels et scipy. Vous pouvez aussi utiliser Google Colab, qui fait fonctionner des notebooks dans le navigateur, sans installation, avec toutes ces bibliothèques (un compte Google est nécessaire).

Rien ne vous empêche d’utiliser Jupyter dès le début, si vous préférez un seul outil.

Les fichiers de données

Plusieurs chapitres utilisent des fichiers de données (dans le dossier donnees qui accompagne ce document) : notes.csv, fable.txt, et trois jeux de données réels très utilisés pour apprendre l’analyse de données : penguins.csv (des manchots de l’Antarctique), titanic.csv (des passagers du Titanic) et flights.csv (le trafic d’une compagnie aérienne de 1949 à 1960). Placez votre notebook ou votre script dans le même dossier que le dossier donnees.

Console ou fichier ?

Il y a deux façons de faire exécuter du code Python :

  1. dans une console (le prompt >>>) : chaque instruction est exécutée dès que vous appuyez sur Entrée. C’est pratique pour faire de petits essais ;

  2. dans un fichier .py (un script) que l’on fait exécuter en entier. C’est ce que l’on fait dès que le programme fait plus de quelques lignes, car on garde une trace de ce que l’on a écrit.

En ligne de commande (dans un terminal), on lance la console avec python (ou python3) et on exécute un script avec python nom_de_mon_fichier.py. Assurez-vous d’utiliser Python 3 (la console affiche sa version au démarrage) : ce document ne s’applique pas à Python 2, qui n’est plus utilisé.

Un outil précieux : Python Tutor#

Certains exemples de ce document sont accompagnés d’un lien « Voir ce code s’exécuter pas à pas dans Python Tutor ». Le site Python Tutor permet d’exécuter un programme instruction par instruction (bouton Next) en dessinant à chaque étape les variables et leurs valeurs. C’est l’équivalent d’un enseignant qui expliquerait au tableau ce qui se passe dans la machine : n’hésitez pas à l’utiliser dès qu’un code vous semble mystérieux, y compris le vôtre !

Voici un premier exemple à essayer :

prenom = "Aude"
age = 20
age = age + 1
print(prenom, "a", age, "ans")

Méthode de travail conseillée#

Pour chaque chapitre :

  1. Lisez les objectifs pour savoir où vous allez.

  2. Lisez une section en retapant et en exécutant les exemples. Modifiez-les : que se passe-t-il si… ?

  3. Répondez aux questions « Testez-vous » avant de regarder la réponse. Si vous vous êtes trompé·e, relisez la section : c’est normal et c’est comme ça qu’on apprend.

  4. Faites les exercices dans l’ordre. Cherchez au moins 10 à 15 minutes avant d’ouvrir l’indice, puis encore un peu avant d’ouvrir la solution. Une fois la solution lue, refaites l’exercice sans la regarder.

  5. Faites le bilan en fin de chapitre : cochez ce que vous savez faire et revenez sur ce qui reste flou.

Que faire quand on est bloqué·e ?

  1. Lisez le message d’erreur en entier, et en particulier sa dernière ligne (nous apprendrons à les lire dès le chapitre 1).

  2. Affichez vos variables avec print à différents endroits du programme pour vérifier qu’elles contiennent ce que vous croyez.

  3. Exécutez votre code pas à pas dans Python Tutor ou dans Thonny.

  4. Expliquez votre code à voix haute, ligne par ligne, comme si vous l’expliquiez à quelqu’un d’autre (même à un canard en plastique : c’est une technique reconnue chez les programmeurs !). On trouve souvent l’erreur en cours de route.

  5. Faites une pause. Sérieusement : la solution vient souvent après.

C’est parti !
